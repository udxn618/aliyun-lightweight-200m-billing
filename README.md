## 200M峰值带宽到底是什么意思？和“固定200M”差在哪

阿里云官方问答里给过明确解释：峰值带宽是速度的上限，没有带宽承诺。日常状态下你的基础带宽可能只有10Mbps左右，流量激增时可以短暂冲到200Mbps（约25MB/s），持续大约10分钟，之后回落到基础值。

这种特性决定了它的适用场景是“脉冲式”的：

- 限时促销页面突然来一波访问

- 小程序启动时的秒级API请求高峰
